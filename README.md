# Breakdown of the Continuum Limit in Loosely Coupled Ring Chains

**Transition, intermittency, and chaos in transversely driven polycatenated ring chains**

> **Status:** Pre-proposal stage. The repository currently holds the environment setup, literature notes, and baseline tooling. No new results have been produced yet.

---

## Overview

A loosely coupled (polycatenated) ring chain driven transversely at one end carries a regular traveling wave. There is no static pretension: tension is generated by the motion itself, and individual links can go slack. As long as the wavelength λ is large compared with the inter-ring spacing a ≡ d<sub>m</sub> + d, the wave is described well by a continuum (string) model, and λ is nearly independent of the drive frequency.

Preliminary LSDEM simulations and experiments show that this description fails abruptly once **λ/a drops below about 8**. Below that point the response becomes irregular and switches intermittently between windows of periodic propagation and irregular bursts.

Linear discreteness cannot account for this. For a beaded string,

```
ω² = (4T / m a) · sin²(ka / 2)
```

At λ = 8a (ka = π/4), the phase velocity differs from the continuum value by only about 2.5%, and the Brillouin-zone edge (λ = 2a) is far away. Something nonlinear and specific to the discrete, tension-only structure must be responsible.

This project asks **why the continuum approximation fails near λ ≈ 8a, and by what dynamical route it fails.**

## Research questions

| | Question | Working hypothesis |
|---|---|---|
| **RQ1** Transition | Is λ/a the true control parameter, and what sets λ<sub>c</sub>/a ≈ 8? | The onset of transient link slackening and re-tensioning ("snap" events). Commensurability locking is the main alternative. |
| **RQ2** Intermittency | What type of intermittency appears at onset? | Not a clean Pomeau–Manneville type, because slack events are nonsmooth. It will be identified from P(τ) and ⟨τ⟩(ε). |
| **RQ3** Chaos | Is the steady irregular regime deterministic chaos, and is it absolute or convective? | The maximal Lyapunov exponent is positive. Comoving exponents decide whether the chaos is generated locally or amplified downstream. |
| **RQ4** Modeling | Can a minimal point-mass chain with unilateral links reproduce λ<sub>c</sub>/a and the route? | Yes. The bifurcation that destroys the regular wave can be found by continuation. |

## Approach

The primary tool is the **Level Set Discrete Element Method (LSDEM)**. Existing experimental data serve as independent validation, and a reduced model provides the theoretical backbone.

1. **Mapping the transition.** λ/a is swept by two independent routes:
   - Varying the drive parameters that enter the analytic expression for λ, at fixed geometry.
   - Varying the ring geometry (and hence a), at fixed drive.

   If both routes collapse onto one curve, λ/a is the control parameter. The order parameters are MFER, the fraction of slack links φ<sub>s</sub>, the snap-event rate, and spectral content. A fine sweep near integer values of λ/a tests for commensurability.

2. **Characterizing intermittency.** Laminar windows are detected using a stroboscopic return distance and a wavelet-energy criterion. From these we measure:
   - the laminar-duration distribution P(τ);
   - the scaling of the mean laminar duration ⟨τ⟩ with ε = (λ<sub>c</sub> − λ)/λ<sub>c</sub>.

   The results are compared against intermittency types I, II, III, V, and on-off. The same pipeline is applied to the experimental records.

3. **Establishing chaos.** The maximal Lyapunov exponent is computed in LSDEM with the twin-trajectory method and Benettin renormalization. Supporting analyses include:
   - finite-time exponents computed separately in laminar and burst windows;
   - lifetime statistics, to rule out transient chaos;
   - comoving (velocity-dependent) Lyapunov exponents Λ(v), to separate absolute from convective chaos;
   - Poincaré sections, as supporting evidence only.

   For the short, noisy experimental data, the 0-1 test for chaos and recurrence quantification are used instead of direct exponent estimates.

4. **Reduced model.** Rings are modeled as point masses and links as unilateral constraints with an impact law. The model is integrated event-driven, and saltation matrices give exact variational dynamics. Periodic waves are continued in λ/a to identify the bifurcation at λ<sub>c</sub>/a.

## Reproducibility notes

**Determinism is required for Lyapunov exponents.** The twin-trajectory method only works if two identical runs stay bitwise identical. Parallel reductions can break this, so every LSDEM build must pass a zero-perturbation twin test before any exponent is computed. LSDEM runs used for exponent calculations should be single-threaded or use fixed-order reductions.

**Steady state only.** All statistics are taken after the recruitment transient has ended. This is verified by checking that running averages of mean slackness and energy are stationary.

**Configuration tracking.** Every simulation output should record the commit hash, input deck, and random seed (if any).

## Data policy

Experimental data are not committed to this repository. Access follows the terms set by the data owners. Large simulation outputs are stored outside Git, and only summary files and scripts needed to regenerate figures are tracked.
